## 📖 Overview

This module introduces the fundamentals of SQL and covers the essential commands used to create, modify, and manage relational databases. It also explains different SQL command categories and commonly used constraints for maintaining data integrity.

This serves as the first practical step toward writing SQL queries.

---

## 🎯 Learning Objectives

- Understand SQL fundamentals
- Learn SQL command categories
- Create databases and tables
- Insert and modify records
- Understand table constraints
- Differentiate DELETE, DROP and TRUNCATE
- Build a strong SQL foundation

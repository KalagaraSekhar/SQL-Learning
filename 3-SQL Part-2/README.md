## 📖 Overview

This module focuses on intermediate SQL concepts and query techniques used to retrieve, filter, sort, modify, and analyze data efficiently. It covers important SQL functions, operators, pattern matching, and commonly asked query problems involving salaries and aggregate calculations.

This module builds upon the SQL fundamentals learned in SQL Part 1 and strengthens practical SQL problem-solving skills.

---

---

🎯 Learning Objectives
Understand SELECT and DISTINCT statements
Sort query results using ORDER BY
Update and delete records
Restrict query results using LIMIT
Find minimum and maximum values
Solve nth highest and lowest salary problems
Use aggregate functions such as COUNT, AVG, and SUM
Understand pattern matching using LIKE and wildcards
Apply SQL concepts through practical questions

## 📖 Overview

This module focuses on **SQL aliases and JOIN operations** used to combine and retrieve related data from multiple tables. It covers different types of JOINs, including INNER JOIN, LEFT OUTER JOIN, RIGHT JOIN, FULL JOIN, and SELF JOIN.

This module builds upon the SQL querying concepts learned in **SQL Part 2** and strengthens practical skills in working with relational databases and multi-table queries.

---

## 🎯 Learning Objectives

* Understand the concept of SQL aliases
* Use aliases for tables and columns
* Understand the fundamentals of SQL JOIN operations
* Retrieve matching records using INNER JOIN
* Understand LEFT OUTER JOIN
* Understand RIGHT JOIN
* Understand FULL JOIN
* Understand and implement SELF JOIN
* Combine data from multiple related tables
* Apply JOIN concepts through practical SQL questions

## 📖 Overview

This module focuses on **MySQL fundamentals and SQL basics**, providing an introduction to databases, SQL, and the execution of SQL queries.

The module covers the **MySQL environment**, introduction to databases, the purpose of SQL, how SQL statements are executed, and the installation of MySQL for practical SQL development.

This module establishes the foundation required to work with **MySQL databases** and execute SQL queries effectively.

---

## 🎯 Learning Objectives

* Understand the fundamentals of MySQL
* Understand the concept of databases
* Learn the basics of SQL
* Understand why SQL is used
* Understand how SQL statements are executed
* Learn the MySQL environment
* Install and configure MySQL
* Understand the relationship between SQL and databases
* Build a foundation for practical SQL development

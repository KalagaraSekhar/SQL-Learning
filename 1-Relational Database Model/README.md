## 📖 Overview

The Relational Database Model is the foundation of every modern relational database system. This module focuses on understanding how data is organized into relations (tables), the principles governing relational databases, and the different types of keys used to maintain data integrity and relationships.

Mastering these concepts is essential before writing SQL queries or designing databases.

---

## 🎯 Learning Objectives

- Understand the Relational Database Model
- Learn E.F. Codd's Rules
- Differentiate between various database keys
- Understand entity relationships
- Learn how keys ensure data integrity
- Build a strong DBMS foundation
